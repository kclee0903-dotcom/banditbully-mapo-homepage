브랜드형 랜딩페이지 정적 파일입니다.

## 구성

- `index.html`: 페이지 구조, SEO 메타 태그, 본문, FAQ, 카카오톡/전화 상담 연결
- `style.css`: 반응형 레이아웃, 브랜드 스타일, 모바일 하단 고정 상담 버튼, hero/시공 공정 이미지 스타일
